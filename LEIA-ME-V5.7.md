# Inteligência Artificial Estendida — V5.7, certificado fiel ao modelo aprovado

## Publicação
Copie **todos** os arquivos da pasta para a raiz da mesma branch atualmente publicada em GitHub Pages. Os arquivos `certificado-arte-premium.png`, `certificado-padrao.js` e `qr-local.js` precisam estar ao lado de `profissional.html`.

## Certificados reais
Somente a função de consulta ao Supabase (`my_course_certificate`) fornece dados de certificados emitidos. A arte-base contém o curso e os elementos decorativos fixos; os nomes, data, emissor, responsável, código e QR Code são desenhados dinamicamente no navegador com a emissão existente. Não há emissão por clique local nem geração de códigos fictícios.

## Como imprimir
Abra o certificado após login, selecione **Imprimir / salvar PDF** e escolha A4 **paisagem** e uma página. O documento é renderizado como uma imagem única para evitar problemas de colunas cortadas ou folha extra no Android.

## Limites
Este QR Code consulta o registro do curso e não constitui assinatura digital. O código só é autêntico se o sistema Supabase confirmar a emissão. A imagem `certificado-arte-premium.png` isolada é **arte-base**, não certificado e não possui validade.
